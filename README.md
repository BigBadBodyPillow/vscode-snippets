## Css

### Reset
A css reset file that i use in all projects.
Sets up the basics like:
* no margin or padding,
* border-box,
* font imports and custom variables
* font size and spacing variables
* background, text, text-invert, accent variables
* scrollbar colour
* body, h1, h2, and a basic font styling
* focus styling
* selection styling
